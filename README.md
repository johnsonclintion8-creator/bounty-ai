# BountyAI — Automated Web Recon & Security Triage

**Turn 3 hours of manual recon, JS auditing, and report drafting into a 30-second automated workflow.**

BountyAI crawls authorized targets, fingerprints tech stacks and security headers, inspects exposed JavaScript assets and hidden parameters, and uses AI triage to generate prioritized, non-destructive verification checklists plus **1-click Burp Suite Scope JSON** and **client-ready PDF/Markdown/HTML reports**.

---

## Why BountyAI? (Manual Workflow vs. BountyAI)

| Task | Manual Researcher Time | BountyAI |
| :--- | :--- | :--- |
| **Attack Surface & Parameter Discovery** (crawling pages, mapping forms, hidden inputs) | 20 – 40 mins | ~5 sec |
| **JS Asset & Library Auditing** (spotting legacy frameworks, dev builds, custom endpoints) | 30 – 45 mins | ~5 sec |
| **Header & Cookie Security Grading** (HSTS, CSP, `SameSite`, server/ALB metadata) | 10 – 15 mins | ~2 sec |
| **Vulnerability Triage & Test Plan Drafting** (correlating assets to XXE, CSTI, IDOR, Open Redirects) | 20 – 30 mins | ~10 sec |
| **Client Deliverable & Burp Suite Setup** (formatting PDF report + building Burp Target Scope JSON) | 30 – 60 mins | ~5 sec |
| **Total Time** | **~1.5 – 3 Hours** | **~25 – 30 Seconds** |

## Key Features
* **Automated Recon & Stack Fingerprinting:** Grades 6 core HTTP security headers (`A`–`F`), flags insecure cookie attributes, and identifies frontend/backend frameworks.
* **JavaScript & Hidden Parameter Mining:** Extracts script paths, form inputs, and query parameters for rapid logic and injection triage.
* **AI-Powered Triage Checklists:** Correlates discovered assets into prioritized, safe verification steps without noisy automated fuzzing.
* **4-Format Instant Export:** Download **Markdown (`.md`)**, **Branded HTML (`.html`)**, **Client PDF (`.pdf`)**, and **Burp Suite Scope (`.json`)** in one click.
* **Built-In Scope & Safety Guardrails:** Blocks private/internal IP ranges (SSRF protection) and supports single-target/CTF mode alongside domain recon.

## Quick Start (Local Setup)

```bash
git clone https://github.com
cd bounty-ai
pip install -r requirements.txt
streamlit run app.py
```

Configure your `.env` or `.streamlit/secrets.toml` with your `GEMINI_API_KEY` and `DATABASE_URL` before launching.

# BountyAI — Automated Web Recon, Burp Suite Bridge & Security Triage

**Turn 3 hours of manual recon, JS auditing, and report drafting into a 30-second automated workflow.**

BountyAI crawls authorized targets, fingerprints tech stacks and security headers, inspects exposed JavaScript assets and hidden parameters, and uses AI triage to generate prioritized, non-destructive verification checklists plus **1-click Burp Suite Scope JSON**, **Burp XML HTTP History Triage**, and **client-ready PDF/Markdown/HTML reports**.

## Two-Way Burp Suite Workflow
1. **Recon -> Burp Suite (`_burp_scope.json`):** Run a 30-second scan on your authorized target and click **Download Burp Scope (.json)** to load discovered hosts and static-asset exclusions straight into Burp Suite (**Target -> Scope -> Settings -> Load**).
2. **Burp Suite -> AI Triage (`.xml` HTTP History Audit):** Export captured requests from Burp (**Proxy -> HTTP history -> Save items**) and drop the `.xml` file into BountyAI's **File Audit** tab. BountyAI safely extracts unique methods, endpoints, and parameter names (stripping sensitive `Cookie` and `Authorization` values) and flags IDOR, access-control, and business-logic test vectors.

## Key Features
* **Automated Recon & Stack Fingerprinting:** Grades 6 core HTTP security headers (`A`–`F`), flags insecure cookie attributes, and identifies frontend/backend frameworks.
* **JavaScript & Hidden Parameter Mining:** Extracts script paths, form inputs, and query parameters for rapid logic and injection triage.
* **Burp Suite Scope Export & XML Traffic Analyzer:** Seamless two-way integration with Burp Suite Community and Pro.
* **4-Format Instant Export:** Download **Markdown (`.md`)**, **Branded HTML (`.html`)**, **Client PDF (`.pdf`)**, and **Burp Suite Scope (`.json`)** in one click.
* **Built-In Scope & Safety Guardrails:** Blocks private/internal IP ranges (SSRF protection) and supports single-target/CTF mode alongside domain recon.

## Quick Start (Local Setup)

```bash
git clone https://github.com/johnsonclintion8-creator/bounty-ai.git
cd bounty-ai
pip install -r requirements.txt
streamlit run app.py
```

Configure your `.env` or `.streamlit/secrets.toml` with your `GEMINI_API_KEY` and `DATABASE_URL` before launching.

# BountyAI — Automated Web Recon & Security Triage

**Turn 3 hours of manual recon, JS auditing, Burp setup, and report drafting into a 30-second automated workflow.**

BountyAI is a cloud-ready reconnaissance and vulnerability triage platform built for bug bounty hunters and application security engineers. It combines active crawling, multi-source passive OSINT, cross-scan change detection, program policy filtering, and two-way Burp Suite integration in one browser workflow.

---

## What Makes BountyAI Different?

| Capability | Typical CLI Recon Wrappers | **BountyAI** |
| :--- | :--- | :--- |
| **Program Scope & N/A Gatekeeper** | Dumps noisy findings that get closed as Informative/N/A | **Parses pasted HackerOne/Bugcrowd rules to tag `[IN-SCOPE]`, `[OUT-OF-SCOPE]`, and `[EXCLUDED / N/A RISK]`** |
| **Cross-Scan Attack Surface Drift Monitor** | Stateless one-off text dumps | **Compares repeat scans in Postgres to spotlight newly deployed JS bundles & endpoints** |
| **Passive OSINT & Schema Harvester** | Requires configuring 5+ separate CLI tools & API keys | **Built-in Shodan InternetDB (ports/CVEs), Wayback CDX parameters, `.js.map` / OpenAPI probes & 1-click GitHub/Google dorks** |
| **Two-Way Burp Suite Bridge** | Manual copy-pasting of URLs | **1-click Burp Target Scope (`.json`) export + Burp Proxy HTTP History (`.xml`) AI logic/IDOR triage** |
| **Client-Ready Deliverables** | Raw terminal output | **Instant PDF, Branded HTML, Markdown & JSON exports** |

## Quick Start (Local Setup)

```bash
git clone https://github.com
cd bounty-ai
pip install -r requirements.txt
streamlit run app.py
```

Configure `.env` or `.streamlit/secrets.toml` with `GEMINI_API_KEY` and `DATABASE_URL` before running.

## Responsible Use Disclaimer
BountyAI is intended strictly for **authorized security testing, bug bounty programs with explicit scope permission, and intentionally vulnerable training targets**. Never scan systems without prior written authorization.

# BountyAI Recon SaaS

Authorized Web, CTF & Bug Bounty Attack Surface Mapper powered by Gemini 3.8 Flash.

## Environment Variables
- `GEMINI_API_KEY`: Required for AI vulnerability triage reports
- `STRIPE_SECRET_KEY`: Optional Stripe secret key for Pro subscriptions
- `STRIPE_PRICE_ID`: Optional Stripe recurring monthly price ID
- `APP_URL`: Public URL of your deployed app (e.g., https://onrender.com)
